# python-renaultimmcode
Vibe-coded python rewrite so a old DOS pascal app doesn't get lost (RenaultImmCode.exe recreation)

RenaultImmCode is a old DOS app that computes old renault cars' pin code from the label inside the key.
Useful when you buy a old renault with a key but no pin card. Pretty useless for most other use.
Was useful one time for my old Twingo, kept the binary, looks like it's almost a lost media by now, so I asked claude to rewrite it.
AFAIK, nobody knew about the ++ password with debug log, so that's new.
